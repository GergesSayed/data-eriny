## 🇪🇬 كيف تستخدم النظام (دليل سريع)

### 🎯 الفكرة باختصار:

النظام مكون من **3 طبقات** بتشتغل مع بعض:

```
جهازك المحلي              Firebase Realtime ☁️        أي جهاز (موبايل/كمبيوتر)
───────────              ────────────────────        ─────────────────────────
أنت بتسحب بيانات          قاعدة بيانات سحابية         CRM بيقرأ البيانات من
الشركات من على           سريعة ولحظية بتخزن          السحابة ويوريك كل
جهازك (Python)           كل الشركات والمكالمات       الشركات وبياناتها فوراً
```

---

### 📱 الخطوة 1: افتح الـ CRM من أي جهاز

افتح الرابط ده من أي متصفح (موبايل أو كمبيوتر):

**🔗 https://data-eriny.vercel.app**

```
البريد: admin@fleet.com
كلمة المرور: admin123
```

ده بيدخلك على واجهة إدارة العملاء — تقدر تشوف الشركات، تسجل مكالمات، تدير الصفقات، وكل حاجه.

---

### 💻 الخطوة 2: اسحب بيانات شركات جديدة (من الكمبيوتر بس)

على جهاز الكمبيوتر بتاعك:

1. افتح مجلد المشروع → `scraper/`
2. اضغط مرتين على **`START.bat`**
3. اختار رقم **1** (سحب سريع + رفع للسحابة)
4. استنى شوية — السكريبت هيسحب شركات ويرفعها للسحابة

**الشركات الجديدة هتظهر فوراً على الموقع من أي جهاز!**

---

### 🔄 إزاي البيانات بتتوحد بين كل الأجهزة؟

| الخطوة | اللي بيحصل |
|--------|-----------|
| 1 | بتشغل السكرابر على جهازك → بيسحب شركات حقيقية وموثقة |
| 2 | سكريبت الرفع بيرفع الشركات فوراً لسحابة الـ CRM المباشرة (Firebase Realtime Cloud) لحظياً |
| 3 | أي حد يفتح الموقع (موبايل/كمبيوتر تاني) → CRM بيستقبل البيانات فوراً عبر تقنية البث المباشر (SSE / Realtime Stream) |
| 4 | لو أي مندوب سجل مكالمة أو حدد موعد متابعة أو أضاف شركة → بتترفع فوراً للسحابة وكل الزملاء يشوفوها لحظياً بدون تعارض |

---

### 🧩 الصفحات الرئيسية في الـ CRM:

| الصفحة | بتعمل إيه |
|--------|----------|
| **لوحة التحكم** | إحصائيات ورسوم بيانية فورية وتوزيع قطاعات الأساطيل |
| **الشركات** | قاعدة بيانات كبرى (25,929+ شركة ومصنع) — بحث فوري مع Web Worker وتصفية وتعيين مناديب |
| **سجل المكالمات** | تتبع المكالمات ومواعيد المتابعة وتاريخ التواصل مع كل شركة |
| **التقارير** | تحليلات القطاعات، مناطق القاهرة الكبرى الصناعية، ومؤشرات الأداء |
| **متابعة الفريق** | مؤشرات التواجد اللحظي للمناديب (Online Presence) ومنع تضارب المكالمات |
| **إدارة الموظفين** | إضافة مناديب جدد وإدارة الصلاحيات |
| **سحب البيانات** | استعراض واعتماد دفعات جديدة من مصانع ومناطق مصر الصناعية |

---

### 🚀 خيارات START.bat:

| رقم | الوظيفة | الوقت المتوقع |
|-----|---------|--------------|
| 1 | **سحب سريع + رفع للسحابة (موصى)** | 2-5 دقائق |
| 2 | Google Maps Browser Scraper | 10-20 دقيقة |
| 3 | Google Maps Deep Scraper | 30-60 دقيقة |
| 4 | Smart Puller | 20-40 دقيقة |
| 5 | Mega Scraper (كل المصادر) | 1-2 ساعة |
| 6 | رفع للسحابة بس (بدون سحب) | 30 ثانية |
| 7 | فتح CRM أونلاين | فوري |
